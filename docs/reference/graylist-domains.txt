GRAYLIST — TRIAGED STATUS  (mixed-content platforms: legit, but host NSFW)
================================================================================
Last updated: 2026-06-12   ·   Original inventory generated: 2026-04-27

This is the LIVE handling status of every graylist domain — what mechanism (if
any) Oath Light applies to each, and why. It replaces the old raw category dump.

Mechanisms:
  API      → graylist-inject.js strips NSFW items from the JSON the site fetches
  DOM      → content.js removes adult items from server-rendered pages + blocks
             adult content pages outright
  DISCORD  → content.js blocks age-restricted channels/servers (DOM age-gate)
  BLACKLIST→ whole-site blocked at navigation (curated domains_part*.json)
  DECIDED  → deliberately left alone (documented decision, not an oversight)
  TODO     → buildable, not done yet
  CANT     → not technically feasible (E2E / no public structure)

Counts: ~110 domains · ~79 actively handled · ~31 not (see bottom).
        (+8 added 2026-06-12 beyond the original scrape — Steam, itch.io, Weasyl,
         PeerTube, Lemmy, Mangadex, ArtStation, Flickr. The 2026-04-27 inventory
         was never complete; audit for more big platforms before trusting it.)
